### 🧭 Öğrenme rotam

CCNA kapsamındaki ağ teknolojileri ve Linux sunucu yönetimi üzerine ilerlemek istiyorum.
Teoriyi küçük laboratuvar çalışmalarıyla uygulamaya dönüştürmeyi hedefliyorum.

| Alan | Çalışma hedefim |
| :--- | :--- |
| 🌐 Ağ temelleri | TCP/IP, subnetting, DNS ve DHCP |
| 🔀 Ağ kurulumu | Switching, routing, VLAN ve NAT |
| 🐧 Linux & sunucular | Komut satırı, SSH, kullanıcılar ve servis yönetimi |
| 🛡️ Ağ güvenliği | Güvenlik duvarları, erişim kuralları ve ağların ayrılması |

                    [ Router ]
